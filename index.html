O Meu Financeiro é um aplicativo desenvolvido com finalidade acadêmica para facilitar o controle de receitas, despesas e compromissos financeiros.

Sobre o projeto

O objetivo do Meu Financeiro é oferecer uma ferramenta simples, intuitiva e acessível para ajudar na organização financeira pessoal.

O projeto permite estudar conceitos de desenvolvimento de aplicativos, interfaces, armazenamento de dados, autenticação e integração com serviços de backend.

Funcionalidades

Controle de receitas

Cadastro e acompanhamento de entradas financeiras.

Controle de despesas

Organização de gastos e contas a pagar.

Calendário

Seleção de datas para transações e lembretes.

Lembretes

Registro de compromissos financeiros e vencimentos.

Autenticação

Integração em desenvolvimento com o Supabase para cadastro, login e recuperação de senha.

Resumo financeiro

Visualização dos valores de receitas e despesas cadastradas.

Tecnologias utilizadas

React Native Expo JavaScript SQLite Supabase GitHub

Desenvolvimento acadêmico

Este projeto tem caráter educacional e está em desenvolvimento.

O aplicativo não realiza operações bancárias reais e não representa nenhuma instituição financeira.
